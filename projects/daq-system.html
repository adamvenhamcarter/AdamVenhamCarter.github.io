Thermal & Flow Data Acquisition System

A modular Arduino data-acquisition platform built to record temperature, flow, and heat flux while supporting pump-control development.

Arduino UnoMAX31856ADS1115MATLABPWM

Objective

Build a single acquisition system capable of collecting multiple thermal measurements at useful resolution while remaining easy to calibrate, debug, and expand for active flow control.

Add a system architecture diagram.
Arduino Uno → 4× MAX31856 thermocouple interfaces → ADS1115 / heat-flux sensor → flow sensor → serial logger → MATLAB.

System architecture

The system integrates four T-type thermocouple channels through MAX31856 converters, a FluxTeq heat-flux sensor measured through a 16-bit ADS1115 ADC, and a flow sensor. Serial output is formatted for post-processing and plotting.

  • Four independent temperature channels with cold-junction measurements and fault detection.
  • Low-level heat-flux signal acquisition through a dedicated ADC.
  • Flow-rate acquisition and calibration correction.
  • MATLAB/Python workflows for reviewing recorded datasets.
  • Pump PWM control planned as part of closed-loop experimental operation.

Debugging & validation

A substantial part of the project involved isolating intermittent thermocouple faults, over/under-voltage errors, invalid cold-junction values, serial logging issues, and channel-specific behavior. Individual channels were tested independently before reintegration.

Engineering takeaway

The project demonstrates sensor integration, signal conditioning, calibration, embedded debugging, data handling, and the practical challenge of making multiple interfaces work reliably as one experimental system.
